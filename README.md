# 🚦 TrafficMind AI
## Tamil Nadu Traffic Congestion Prediction System

**Developer:** Lalith Krish  
**Year:** 2026  
**Domain:** Artificial Intelligence / Machine Learning  

TrafficMind AI is a full-stack Artificial Intelligence web application that predicts **traffic congestion levels across all 38 districts of Tamil Nadu**.  
The system uses Machine Learning models trained on traffic pattern data and provides **instant congestion predictions, interactive dashboards, and route visualisation**.

# 📊 Project Highlights

- 🚦 Traffic prediction for **38 Tamil Nadu districts**
- 🤖 **3 Machine Learning Models**
- 🎯 **92.64% Prediction Accuracy**
- 📊 Interactive **Dashboard with Charts**
- 🗺 **India Route Map Visualisation**
- 📂 **CSV Data Import for Batch Prediction**
- 📡 **REST API Backend**
- 🌐 **Offline First Design**

---

# 🧠 Machine Learning Models

| Model | Accuracy | F1 Score |
|------|------|------|
| Random Forest | **92.64%** | 0.926 |
| Gradient Boosting | 90.81% | 0.907 |
| Logistic Regression | 76.34% | 0.760 |

**Selected Model:** Random Forest  
Reason: Highest accuracy and better handling of complex traffic patterns.

# 📌 Features Used for Prediction

The model uses **14 engineered features**:

1. Hour
2. Day of Week
3. Month
4. District
5. Temperature
6. Rainfall
7. Vehicle Count
8. Average Speed
9. Road Capacity
10. Holiday Indicator
11. Weekend Indicator
12. Special Event Indicator
13. Road Type
14. Accident Count
